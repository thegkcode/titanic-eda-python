# Titanic Dataset — Exploratory Data Analysis

## Overview
This project explores the Titanic passenger dataset using Python to understand passenger characteristics and survival patterns through statistical analysis and data visualization.

## Objectives
- Understand the dataset structure and feature types.
- Identify missing values and potential outliers.
- Perform univariate, bivariate, and multivariate analysis.
- Explore survival patterns across passenger demographics and ticket classes.
- Examine relationships between features such as age, sex, passenger class, and fare.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Notebook
- `titanic-eda.ipynb` — Data exploration, statistical summaries, visualizations, and feature relationship analysis.

## Key Analysis Areas
- Passenger age and fare distributions
- Survival rate and passenger class
- Survival patterns by sex and age
- Missing-value analysis
- Relationships among passenger features

## How to Run
1. Clone or download this repository.
2. Install the required libraries.
3. Place `train.csv` in the expected directory or update the file path in the notebook.
4. Open `titanic-eda.ipynb` in Jupyter Notebook.
5. Run the cells from top to bottom.

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```
